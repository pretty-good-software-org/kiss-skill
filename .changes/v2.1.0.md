## [v2.1.0] - 2026-11-10
### Added
- Validate optional Claude marketplace dependencies with the released `skillctl validate claude-plugin` command,
  replacing the copied `tools/validate_skillctl.py` adapter.
- Generate `.claude-plugin/plugin.json` from `apm.yml` with `apm pack`, and fail `test:default` through
  `test:plugin-manifest` when the committed manifest drifts from that output.
- Run `lint:audit` in `lint:default` so osv-scanner fails the build on a known advisory in `uv.lock`.
### Fixed
- Start new Agent Skill projects at Python package version 0.1.0-alpha.1 instead of the template's own release version.
- Pin shellcheck and assert it in the actionlint task, so workflow shell linting runs instead of being skipped silently.
- Run every `uv run` in the Mise tasks and Lefthook hooks with `--locked` and switch Dependabot to the `uv` ecosystem,
  so a dependency bump that skips `uv.lock` fails CI and hooks instead of being re-locked silently; refresh the stale
  `uv.lock`.
- Move Ruff `select` under `[tool.ruff.lint]` so Ruff stops warning about deprecated top-level linter settings; the
  enabled rules are unchanged.
- Exclude generated `apm.lock.yaml` and `apm_modules/` content from Yamllint.
- Declare Mise 2026.7.7 as the minimum version, so an older Mise refuses to run instead of rewriting musl entries in
  `mise.lock` with glibc ones.
