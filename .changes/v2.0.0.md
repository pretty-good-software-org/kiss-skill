## [v2.0.0] - 2026-07-24
### Added
- Establish the standalone Agent Skill repository template with orgctl initialization, spec-aligned metadata validation,
  deterministic packaging, locked Python tooling, a development-only orgctl pin, focused boundary tests, and a full
  derived-repository smoke test.
### Changed
- Replace bespoke Lefthook file-hygiene loops with the pinned pre-commit-hooks executables while retaining Lefthook as
  the orchestrator.
- Adopt the canonical `skills/<plugin-name>/SKILL.md` layout for single-skill plugins, move repository tooling under
  tools/, and make validation enforce the distributable boundary.
- Add vendor-required author metadata so the standalone plugin passes strict Claude Code validation while retaining the
  nested skill boundary.
- Correct the template contract to document vendor-required author metadata in plugin.json.
- Stop emitting one-time consumer guard scaffolding and keep structural validation and initialization smoke tests
  repository-only under tools.
- Migrate repository and plugin validation to the released skillctl v2.0.0 binary, replacing the locally copied
  tools/validate_skill.py; skillctl is pinned in the development profile for local validation via
  `mise run lint:development`.
- BREAKING: migrate standalone plugins to the canonical skills/<plugin-name>/SKILL.md collection layout, add minimal APM
  metadata, and pin skillctl v2.0.0 and APM v0.26.0 with checksummed Mise locks.
### Removed
- Remove non-standard .skill archive packaging so generated plugins contain no placeholder runtime scripts or packaging
  tests and distribute through Agent Skills directories and Claude Code marketplaces.
